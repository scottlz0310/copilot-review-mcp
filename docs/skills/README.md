Mcp-Docker v2.18.0 以降の `mcp-docker skill install` で配置し、`mcp-docker skill status` で配置状態を確認できます。

Copilot 用 MCP ツールは引き続き利用できます。[ツールの利用手順](../watch-tools.ja.md)を参照してください。
